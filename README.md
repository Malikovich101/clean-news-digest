# Clean News Digest

Персональный Telegram-дайджест: очистка ленты от рекламы, точных и смысловых повторов с сохранением исходных публикаций и ссылок на источники.

## Требуемые GitHub Actions Secrets

- `TG_API_ID`
- `TG_API_HASH`
- `TG_SESSION_STRING`
- `TG_BOT_TOKEN`
- `TG_CHAT_ID`
- `GEMINI_API_KEY`

Запуск: 08:05, 14:05 и 20:05 по Перми (UTC+5).
